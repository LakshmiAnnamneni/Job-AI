# resume/

Put your resume files here (PDF, DOCX, Markdown, and so on): for example a master resume plus
versions tailored to specific roles.

**Everything in this folder except this README is gitignored.** Resumes contain personal
details (name, contact info, work history), and this repo is public, so they stay on
your machine and are never committed. Collaborators keep their own resumes here the
same way.

Suggested naming, so versions are easy to match to tracker rows in `data/jobs.csv`:

```
resume/
├── master.docx                      # your full, up-to-date resume
├── 2026-11_tpm.pdf                  # a version tailored to a role type
└── 2026-11_redwire_4480314300.pdf   # a version for a specific job (company + tracker Id)
```
